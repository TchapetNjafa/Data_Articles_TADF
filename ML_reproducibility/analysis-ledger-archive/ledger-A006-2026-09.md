**T4 — `data/ceiling_decomposition.json` audit**
  Stored `rss_floor_eV` = 0.1282 while `rf_mae_eV` = 0.0956 → the model sits **below its own stated floor**.
  The RSS of the three components it names (A 0.072, B 0.195, C 0.296) recomputes to **0.3620**, not 0.1282:
  the stored number is not the RSS of what the file says it is.
  Terms B (sTDA-vs-adiabatic) and C (B3LYP-vs-CAM-B3LYP) are dispersions between *levels of theory*;
  they do not bound the error of a model regressed on *experimental* labels. Only A is a label property.
  **Defensible quantity: RMS standard error of the per-molecule median label = 0.0490 eV**
  (independently reproduces A-003's 0.049), vs model MAE 0.0956 eV.

- **Interpretation.**
  (T1) "The excited-state step adds nothing" is now supportable as a genuine *equivalence* statement
  rather than a failure to reject: Morgan and NTO differ by less than **0.017 eV** with 95% confidence,
  which is well inside the 0.049 eV precision of the label itself. State the margin, not "indistinguishable".
  (T2) That equivalence is an **MAE** verdict and does not hold for ranking under protocol transfer.
  Under the source-paper split the NTO features outrank Morgan by Δρ = +0.191, CI excluding zero — the
  single place in the study where the semi-empirical excited-state step earns its cost, on the very metric
  Methods declares primary for triage. The manuscript currently reports only the Morgan row.
  (T3) No enrichment number should ship until the definition is pinned: the base rate itself does not
  reproduce, and the curve is non-monotone, so "1.2–1.4×" is a cut-dependent summary of a wobbly curve.
  (T4) The RSS-floor construction is unsound twice over (arithmetic and category). The defensible ceiling
  statement uses only the label term, 0.049 eV, and must not claim the model is *at* a floor it is below.
  (T5) The published falsification test was mis-specified, so it neither confirms nor refutes the thesis.
  Conditioning correctly, error is ~30% lower where the label is known reproducible (0.074 vs 0.106) —
  the direction the label-noise account predicts — but with only 23 noisy-label molecules it is not resolved.
- **Caveats.** (i) T5's clean/noisy contrast is unpaired and n_noisy = 23; treat the direction as
  suggestive, the magnitude as unresolved. (ii) T5 subsets are evaluated on existing out-of-fold
  predictions, not retrained per subset — this is error *conditional on* label quality, not a re-fit.
  (iii) T3's base-rate discrepancy (0.446 vs 0.494) is unexplained and may reflect a different threshold
  convention in the older scripts; it must be traced before any triage number is quoted.
  (iv) T2's Δρ bootstrap resamples molecules, not DOI groups, so it does not propagate group-level
  uncertainty; a group-level bootstrap would be wider.
- **Claims:** supersedes the ceiling framing behind C3; qualifies C1; new claims **C10** (equivalence at
  a 0.017 eV margin), **C11** (NTO ranking advantage under protocol transfer, Δρ +0.191 CI excludes zero).
