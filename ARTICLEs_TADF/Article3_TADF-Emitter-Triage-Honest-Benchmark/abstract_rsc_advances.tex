The singlet--triplet gap \deltaest is the screening parameter for thermally activated
delayed fluorescence (TADF), yet independent experimental reports of the same
compound scatter by \qty{0.072}{\electronvolt} RMS, and the per-molecule median
regressed on is known only to \qty{0.049}{\electronvolt}, about half of any model's
error. This noise floor, not model capacity, bounds every predictor.
%
Against that ceiling, two-dimensional structure predicts as accurately as a
semi-empirical excited-state calculation: on \num{231} donor--acceptor molecules
(\num{212} Bemis--Murcko scaffolds, scaffold cross-validation), random forests from
Morgan fingerprints (MAE \qty{0.091}{\electronvolt}) and RDKit descriptors
(\qty{0.100}{\electronvolt}) match natural-transition-orbital descriptors from a
GFN2-xTB/sTDA excited state (\qty{0.096}{\electronvolt}) to within
\qty{0.017}{\electronvolt} on paired folds, so the excited-state step buys no
accuracy.
%
Two further results are specific to this corpus. First, under a source-paper split the
accuracy advantage over a mean-value baseline disappears, but the excited-state
descriptors keep the rank correlation the fingerprints lose (paired
$\Delta\rho = \num{0.19}$ on a single split, \qty{95}{\percent} CI narrowly excluding
zero): they order candidates across laboratories without predicting the gap. Second,
the leakage that inflates many computed-gap models is learner-dependent --- given the
$S_1$ and $T_1$ energies as features, a linear model returns
$\Delta E_\text{ST}\equiv E_{S_1}-E_{T_1}$ exactly ($R^2 = 1.000$) while an
axis-aligned forest on the same features recovers only $R^2 = 0.59$ and clears
cross-validation unremarked.
%
Progress past the $\approx\qty{0.1}{\electronvolt}$ ceiling needs a curated,
solvent-controlled, single-source experimental benchmark rather than a better model.
%
Data, models, and code are available (Zenodo DOI: 10.5281/zenodo.17436069).
