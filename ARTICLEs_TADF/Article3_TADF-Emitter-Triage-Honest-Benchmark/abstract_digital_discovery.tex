Discovering thermally activated delayed fluorescence (TADF) emitters hinges on the
singlet--triplet energy gap (\deltaest), yet high-level excited-state calculations are
costly and disagree with experiment by several tenths of an electronvolt.
%
We ask a narrow question: how accurately can machine learning estimate
\emph{experimental} \deltaest\ from the molecular structure alone, and what limits it?
%
Regressing \deltaest\ on features that include
the $S_1$ and $T_1$ energies is circular---since
\deltaest~$\equiv E_{S_1}-E_{T_1}$, the model merely subtracts two inputs---so we target
the measured gap instead.
%
Using \num{231} donor--acceptor molecules with literature-reported gaps, we train
random forests on three descriptor sets and evaluate them under Bemis--Murcko scaffold
cross-validation (\num{212} distinct scaffolds), holding whole scaffolds out of
training. Models built from the 2D structure alone---Morgan fingerprints
(mean absolute error, MAE \qty{0.091}{\electronvolt}) and RDKit descriptors
(\qty{0.100}{\electronvolt})---match
descriptors derived from a semi-empirical excited-state calculation
(\qty{0.096}{\electronvolt}); the excited-state step adds nothing for the
$S_1$--$T_1$ gap.
%
All sets reach $R^2 \approx 0.25$--$0.31$ with wide confidence intervals and weak ranking
(Spearman \numrange{0.26}{0.36}); the signal is modest but real---below a label-permutation
null at $p = 0.001$---and only slightly above a mean-value baseline
(MAE \qty{0.107}{\electronvolt}).
%
Accuracy is bounded near \qty{0.1}{\electronvolt} by two effects we quantify: scatter
among independent experimental reports (\qty{0.072}{\electronvolt} RMS, up to
\qty{0.56}{\electronvolt}) and functional dependence of the computed reference
(up to \qty{0.58}{\electronvolt}).
%
As a triage filter for low-gap emitters the model enriches only modestly
(\numrange{1.2}{1.4}$\times$ over random). The practical message is cautionary: accuracy is
set by data quality, not model capacity.
%
All data, models, and code are openly available (Zenodo DOI: 10.5281/zenodo.17436069).
