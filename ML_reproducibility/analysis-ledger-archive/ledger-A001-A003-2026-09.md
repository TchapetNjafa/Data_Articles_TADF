### A-001 — Computed sTDA gap as predictor vs structure-only ML (answers Referee 1)

- **Date:** 2026-08-29
- **Question:** Referee 1 (DD rejection) asserts that (a) refusing the computed ΔE_ST as a
  descriptor is inconsistent since other equally-costly computed features are used, and (b) the
  semi-empirical computed gap alone is "much better than the ML gap based on structural parameters
  alone", citing exp-vs-theory r > 0.95 from the literature. Is that true on THIS dataset?
- **Source:** `code/ref1_gap_baseline.py` → `data/ref1_gap_baseline.json`
  Inputs: `MCA_submission/tables/experimental_delta_est_extracted.csv` (experimental ΔE_ST, median
  over reports) · `CALCULATIONS-MADE/data_processing/combined_features_747mol_full_ct.csv`
  (GFN2-xTB/sTDA, gas phase, `Delta_E_ST_eV` + 35 NTO descriptors) · `Data_Ref.csv` (SMILES).
- **Method:** n = 231 molecules, 212 Bemis–Murcko scaffolds. GroupKFold(5) on scaffolds, identical
  folds for every row. RF = 400 trees, `random_state=0`. Bootstrap CI: 2000 resamples, seed 0.
  B2 calibrates the gap *inside each training fold* only (`np.polyfit` degree 1) — no test leakage.
- **Result:**

  | Row | Predictor | MAE / eV [95% CI] | R² [95% CI] | Pearson r | Spearman ρ |
  |-----|-----------|-------------------|-------------|-----------|------------|
  | B0 | mean baseline | 0.107 [0.092, 0.124] | −0.006 [−0.035, −0.001] | −0.106 (p=0.11) | −0.055 |
  | B1 | raw sTDA computed gap | 0.251 [0.230, 0.273] | **−2.216** [−4.83, −1.02] | 0.322 (p=5.6e−7) | 0.237 |
  | B2 | calibrated gap (a·gap+b, in-fold) | 0.104 [0.089, 0.120] | 0.082 [−0.080, 0.176] | 0.288 | 0.229 |
  | M1 | RF Morgan (structure only) | **0.091** [0.078, 0.106] | 0.274 [−0.185, 0.536] | 0.547 (p=2.2e−19) | 0.306 |
  | M2 | RF NTO (energy-free) | 0.096 [0.082, 0.110] | 0.253 [0.012, 0.449] | 0.504 | 0.356 |
  | M3 | RF NTO + computed gap | 0.097 [0.084, 0.112] | 0.240 [−0.012, 0.439] | 0.490 | 0.340 |
  | M4 | RF Morgan + computed gap | 0.091 [0.078, 0.107] | 0.274 [−0.157, 0.541] | 0.545 | 0.307 |

  Signed bias (computed − experimental) = **+0.221 eV**; computed mean 0.370 eV vs experimental
  mean 0.149 eV (SD 0.179 vs 0.167 eV).

- **Interpretation:** The referee's expectation does not hold on this dataset, and the test was run
  the way the referee asked for it. The raw GFN2-xTB/sTDA gap is a **worse** predictor of the
  experimental gap than predicting the dataset mean: MAE 0.251 vs 0.107 eV, R² = −2.2, driven by a
  +0.221 eV systematic overestimation. Removing that offset by fitting a per-fold linear
  calibration — which requires experimental training labels, so it is no longer a zero-parameter
  physics predictor — brings the gap to MAE 0.104 eV, still no better than the mean baseline and
  worse than the structure-only random forest (0.091 eV). Adding the computed gap to either feature
  set changes nothing: NTO 0.096→0.097 eV, Morgan 0.091→0.091 eV, both well inside the bootstrap CI.
  The gap's rank correlation with experiment (ρ = 0.237) is also below both RF models (0.306, 0.356).
  So the descriptor was not withheld for narrative convenience: it carries no incremental
  information about the *experimental* label at this level of theory, and used alone it is
  actively harmful. The r > 0.95 exp-vs-theory agreement the referee cites comes from
  single-study sets measured under one protocol, not from a 231-molecule multi-source compilation;
  here r = 0.322 for the raw semi-empirical gap.
- **Caveats:** (i) GFN2-xTB/sTDA gas-phase vertical only — a higher level of theory (TD-DFT with a
  range-separated functional, or ROKS) may well correlate better, and this entry does not test that.
  (ii) All R² CIs except M2 cross zero; M1-vs-B2 separation rests on MAE and r, not on R².
  (iii) Experimental labels are medians over heterogeneous reports (see Referee 3 point 2) — that
  noise floor caps every row in the table equally, so it does not explain the *ordering*.
  (iv) 212/231 scaffolds are singletons, so GroupKFold ≈ random split here (Referee 3 point 3);
  this weakens the "unseen chemotype" reading but applies identically to all seven rows.
- **Claim link:** C2 (was BLOCKER B1). Supports a direct, evidence-backed answer to Referee 1 and
  supplies a new manuscript table (physics baseline vs ML), which the rejected version lacked.

### A-002 — Referee 3 points 1–3: paired baseline test, label noise, split geometry

- **Date:** 2026-08-29
- **Question:** (P1) With R² CIs crossing zero, is the model distinguishable from a mean predictor?
  (P2) Do uncurated multi-condition labels explain the performance, and does the model survive a
  protocol-level split? (P3) With 92.9% singleton scaffolds, does GroupKFold differ from a random split?
- **Source:** `code/ref3_p1p2p3.py` → `data/ref3_p1p2p3.json`. Same inputs as A-001.
- **Method:** n = 231. RF 400 trees, `random_state=0`. Paired bootstrap (2000 resamples) of the MAE
  *difference* on identical folds, plus Wilcoxon signed-rank on paired absolute errors. Label noise
  from the SD across independent literature reports of the same molecule. DOI-grouped GroupKFold(5)
  over 173 source papers = unseen-protocol split. Scaffold vs random vs DOI CV on identical model.
- **Result:**

  **P1 — model vs mean baseline, paired on identical folds** (positive = model better)

  | Model | ΔMAE / eV [95% CI] | P(better) | Wilcoxon p |
  |-------|--------------------|-----------|------------|
  | Morgan | +0.0160 [+0.0022, +0.0292] | 0.984 | 3.4e−4 |
  | NTO | +0.0117 [+0.0024, +0.0224] | 0.993 | 8.0e−3 |

  **P2a — label noise, 102 multi-report molecules:** SD median 0.000 eV, RMS 0.086 eV, max 0.564 eV;
  58% of multi-report molecules have zero spread.

  **P2b — DOI-grouped CV** (n = 231, 173 papers, k = 5)

  | Predictor | MAE / eV | R² | ρ |
  |-----------|----------|-----|---|
  | Morgan | 0.102 | +0.184 | +0.155 |
  | NTO | 0.099 | +0.142 | +0.346 |
  | mean baseline | 0.108 | −0.010 | — |

  Morgan vs mean under DOI split: ΔMAE +0.0052 eV, CI [−0.0074, +0.0170] — **crosses zero**.

  **P2c — report-count subsets:** single-report (n=129) MAE 0.101 vs baseline 0.123, R² +0.381,
  ΔMAE +0.0223; multi-report (n=102) MAE 0.080 vs baseline 0.089, R² +0.064, ΔMAE +0.0090.

  **P3 — split geometry:** 197/212 scaffolds singleton (92.9%), 1.09 molecules/scaffold, largest
  scaffold 15. Morgan: scaffold CV MAE 0.091 / R² +0.274 · random CV 0.094 / +0.318 · DOI CV 0.102 / +0.184.

- **Interpretation:** The three points do not all survive, and two of them do.
  **P1 is refuted on the correct instrument.** R² is a poor test here: the target SD is 0.167 eV, so
  with n = 231 the R² bootstrap is wide by construction. The claim the paper makes is about MAE, and
  the paired test on identical folds separates cleanly — Morgan beats the mean predictor by
  0.016 eV with a CI excluding zero and Wilcoxon p = 3.4e−4. "Indistinguishable from a mean
  predictor" is therefore not correct as stated; what is correct is that the improvement is *small*
  (15% MAE reduction), which the paper should state as the result rather than defend against.
  **P3 is confirmed.** Scaffold CV (0.091) and random CV (0.094) are within noise of each other, so
  the scaffold split earns no "unseen chemotype" claim and that language must go. The fix is not to
  drop the split but to replace it: DOI-grouped CV (0.102) is measurably harder than both, because
  holding out a source paper holds out a synthetic series and a measurement protocol at once.
  **P2 is confirmed in its consequential half.** Under the DOI split the paired advantage over the
  mean baseline falls to +0.005 eV with a CI crossing zero — the model does not demonstrably
  transfer to an unseen measurement protocol. Part of the apparent scaffold-CV signal was therefore
  within-paper regularity, not structure–property information. Two details cut against the referee's
  stronger reading that the target is simply corrupted: 58% of repeatedly-measured molecules have
  *zero* inter-report spread, and the cleaner multi-report subset gives the *lowest* MAE in the study
  (0.080 eV). So the labels are not uniformly noisy; the transfer failure is at the protocol level,
  not the individual-measurement level. NTO keeps ρ = 0.346 under the DOI split versus Morgan's
  0.155, the one place where the semi-empirical features do outrank fingerprints.
- **Caveats:** (i) DOI groups are a *proxy* for protocol — the source CSV has `phase` and
  `atmosphere` 100% NaN and `record_method` holds the text-mining parser name, not the experimental
  method, so a genuinely condition-controlled subset cannot be built from this data. Say so
  explicitly rather than implying conditions were controlled. (ii) 173 groups over 231 molecules
  means DOI folds are also near-singleton; the split is harder but not deep. (iii) P2a RMS SD = 0.086 eV is a
  DIFFERENT ESTIMATOR from the published 0.072 eV, not a different subset — reconciled in A-003.
  Do not print 0.086; the published 0.072 stands. (iv) Multi-report MAE 0.080 eV partly reflects lower
  target variance in that subset, not only cleaner labels.
- **Claim link:** C1 (revised), C3 (needs reconciliation), and new claim C5 "model does not transfer
  across source protocols". Retires the "unseen chemotype" wording everywhere it appears.

### A-003 — Reconciliation of the two label-noise numbers (closes A-002 caveat iii)

- **Date:** 2026-08-29
- **Question:** A-002 reported label-noise RMS 0.086 eV; the manuscript prints 0.072 eV
  (`data/ceiling_decomposition.json`, component A). Which is right, and is one of them wrong?
- **Source:** `code/reconcile_label_noise.py` → `data/label_noise_reconciled.json`.
  Definition traced to `code/solvent_analysis.py:61-63`; consumer at `code/ceiling_decomposition.py:45-46`.
- **Method:** Recomputed every candidate estimator on the identical 102 multi-report molecules
  (report counts: 80×2, 18×3, 3×4, 1×8) of the 231-molecule benchmark.
- **Result:**

  | Estimator | Value / eV |
  |-----------|------------|
  | molecule-weighted RMS of single report about its median (**published**) | **0.0724** |
  | report-pooled RMS about median | 0.0905 |
  | RMS of per-molecule SD, ddof = 1 (A-002's number) | 0.0856 |
  | RMS of per-molecule SD, ddof = 0 | 0.0701 |
  | RMS standard error of the median label | 0.0490 |
  | mean absolute deviation about median | 0.0312 |

  Ratio ddof-1 SD / pooled-about-median = 0.946. Median per-molecule SD = 0.000 eV;
  max = 0.564 eV; 57.8% of multi-report molecules have zero spread; max spread 1.086 eV.

- **Interpretation:** There is no discrepancy and nothing to correct in the manuscript. The
  published 0.072 eV reproduces to 0.0724 eV and is well defined: for each molecule, the RMS
  deviation of a single report about that molecule's median, averaged with **equal weight per
  molecule**. A-002's 0.086 eV is a different estimator of the same spread — it uses the ddof = 1
  sample SD and therefore weights molecules by report count and inflates by √(n/(n−1)), which is √2
  for the 80 molecules measured twice. Both are arithmetically correct; they answer different
  questions. Keep 0.072 eV for the corpus-heterogeneity statement, since that is the quantity the
  ceiling argument needs: it is the expected error incurred by taking one literature report in place
  of the consensus median. Retire 0.086 eV — it is the largest of the defensible estimates, so
  printing it after 0.072 has appeared would read as inflation. Separately, the RMS standard error
  of the median label is 0.049 eV, roughly half the model MAE of 0.096 eV; that is the number to
  quote if a referee asks how precisely the *target* itself is known, and it does not support a
  claim that label noise alone explains the model's error.
- **Caveats:** (i) All estimators exclude the 129 single-report molecules, for which no
  reproducibility estimate exists at all — so every one of these figures is measured on the 44% of
  the benchmark that happens to have been measured twice, and may not represent the rest.
  (ii) 57.8% zero spread partly reflects the same value being re-reported between papers rather than
  independent re-measurement; the text mining cannot distinguish those, so all six figures are
  lower bounds on true inter-laboratory variability. (iii) `ceiling_decomposition.py` falls back to a
  hardcoded 0.072 when `data/solvent_heterogeneity.json` is absent — the file is present, so the
  live number is computed, but delete the fallback so a missing input cannot silently pass.
- **Claim link:** C3 CLOSED (0.072 eV verified reproducible, definition pinned).
